# 🎵 Canções, Peças, Ritmos

Arquivo digital de canções originais, arranjos, peças instrumentais, ritmos e partituras criadas para Educação Musical.

👉 **[Aceder ao site / Open Live Website](https://github.io)**

---

## 📂 Conteúdo / Contents

- **Ed. Musical (A–Z):** Canções e ritmos organizados alfabeticamente, com gravações áudio e partituras.
- **Arranjos & Arranjinhos…:** Arranjos instrumentais e acompanhamentos.
- **Guitar / Old Songs / Old Songs +:** Peças para guitarra e gravações antigas.
